Mastering WooCommerce Email Template Customization: A Developer's Guide

Hello! I am Shiv Parmar, a WordPress developer based in the bustling city of Rajkot, India. Over the years working with e-commerce clients across the globe, I have noticed one area that store owners frequently overlook: transaction emails. Default WooCommerce emails are functional, but they lack brand identity and often feel cold and generic. Customizing these transactional emails not only reinforces your visual identity but also builds trust and improves customer retention.

In this post, I will walk you through various techniques for customizing WooCommerce email templates, ranging from basic administrative settings to advanced PHP hooks and child theme overrides.

1. The Native Customization Route

Before jumping into custom code, WooCommerce offers built-in customization settings that every developer should set up first. You can access these options directly from your WordPress dashboard by navigating to WooCommerce > Settings > Emails and scrolling down to the Email template options section.

Here, you can adjust:

  • Header Image: Add your company logo URL.
  • Footer Text: Customize copyright notes and contact details.
  • Base Color: Match the primary accent color of your brand.
  • Background & Body Colors: Adjust canvas colors to match your theme.

While these settings provide quick wins, complex branding requirements usually require deeper, code-level changes.

2. Overriding Email Templates in Your Child Theme

When you need to alter the layout or structure of an email, modifying core plugin files directly is a strict no-no, as future WooCommerce updates will overwrite your changes. The standard developer approach is copying template files into your child theme directory.

How to Safely Copy Template Files

WooCommerce core templates are located inside the wp-content/plugins/woocommerce/templates/emails/ folder. To override any template, follow this directory structure within your child theme:

wp-content/themes/your-child-theme/woocommerce/emails/

For example, if you want to customize the customer processing order email:

  1. Locate wp-content/plugins/woocommerce/templates/emails/customer-processing-order.php.
  2. Copy it to wp-content/themes/your-child-theme/woocommerce/emails/customer-processing-order.php.
  3. Edit the copied file safely inside your child theme.

WooCommerce automatically detects the child theme template and loads it instead of the plugin default.

3. Modifying Styling via PHP Filters

Inline CSS is required for optimal email rendering across legacy clients like Outlook and Gmail. WooCommerce generates inline styles automatically, but you can inject custom CSS into all emails using the woocommerce_email_styles filter.

Place the following snippet in your child theme's functions.php file:

/**
 * Add custom CSS to WooCommerce emails
 * Author: Shiv Parmar
 */
add_filter( 'woocommerce_email_styles', 'shiv_custom_woocommerce_email_styles', 10, 2 );
function shiv_custom_woocommerce_email_styles( $css, $email ) {
    $css .= "
        #header_wrapper h1 {
            font-family: 'Helvetica Neue', Helvetica, Roboto, Arial, sans-serif !important;
            font-size: 26px !important;
            color: #1a252f !important;
        }
        .order_details {
            border: 1px solid #e0e0e0 !important;
            margin-bottom: 25px !important;
        }
        .order_details th {
            background-color: #f8f9fa !important;
            color: #333333 !important;
        }
        .td {
            color: #555555 !important;
        }
    ";
    return $css;
}

4. Adding Dynamic Content Using Email Action Hooks

Rather than overriding full template files—which requires maintenance when WooCommerce updates its core files—using action hooks is the cleanest and most resilient method to insert custom content into WooCommerce emails.

Adding Content Above or Below the Order Table

WooCommerce fires standard hooks during email generation. Here is how you can display special order instructions or custom messages conditionally based on the email type:

/**
 * Inject custom messaging into processing order emails
 * Author: Shiv Parmar
 */
add_action( 'woocommerce_email_before_order_table', 'shiv_add_custom_notice_to_email', 20, 4 );
function shiv_add_custom_notice_to_email( $order, $sent_to_admin, $plain_text, $email ) {
    // Target only the Customer Processing Order email
    if ( 'customer_processing_order' === $email->id ) {
        if ( $plain_text ) {
            echo "Note: Our Rajkot fulfillment center is currently processing your items. You will receive tracking details shortly.\n\n";
        } else {
            echo '<div style="background-color: #e8f5e9; border-left: 4px solid #2e7d32; padding: 12px; margin-bottom: 20px;">';
            echo '<p style="margin: 0; color: #1b5e20; font-weight: bold;">Processing Update:</p>';
            echo '<p style="margin: 5px 0 0 0; color: #2e7d32;">Our fulfillment team is carefully preparing your order. You will receive tracking details as soon as it ships!</p>';
            echo '</div>';
        }
    }
}

5. Displaying Custom Order Meta in Emails

If your checkout page collects custom metadata—such as delivery instructions, gift notes, or GST/VAT information—you will want to display this information inside the transactional email.

Below is a practical snippet demonstrating how to retrieve custom order metadata and render it cleanly inside the email output:

/**
 * Display Custom Delivery Instructions Meta in Email
 * Author: Shiv Parmar
 */
add_action( 'woocommerce_email_customer_details', 'shiv_display_custom_meta_in_email', 15, 4 );
function shiv_display_custom_meta_in_email( $order, $sent_to_admin, $plain_text, $email ) {
    // Fetch custom order meta key
    $delivery_notes = $order->get_meta( '_delivery_instructions', true );

    if ( ! empty( $delivery_notes ) ) {
        if ( $plain_text ) {
            echo "----------------------------------------\n";
            echo "Delivery Instructions: " . esc_html( $delivery_notes ) . "\n";
            echo "----------------------------------------\n";
        } else {
            echo '<h3 style="color: #333333; margin-top: 20px;">' . __( 'Delivery Instructions', 'text-domain' ) . '</h3>';
            echo '<p style="background: #f4f4f4; padding: 10px; border-radius: 4px;">' . esc_html( $delivery_notes ) . '</p>';
        }
    }
}

6. Testing Email Templates Locally

Testing transactional emails in real-time can be tedious if you place a new test order every time you make a CSS tweak. Here are two efficient ways to streamline your workflow:

  1. Use Preview Tools: Plugins like MailPoet or specialized email preview plugins allow you to render WooCommerce emails live inside your wp-admin area.
  2. Local SMTP Capture: Tools like Mailpit, Mailtrap, or LocalWP's built-in Mailhog service intercept outgoing site emails locally, preventing spam folder issues and speeding up styling reviews.

Wrapping Up

Customizing WooCommerce email templates is an effective way to elevate brand consistency and build lasting customer relationships. Whether you apply simple CSS adjustments via hooks or rewrite structural markup inside your child theme, always prioritize clean, maintainable code over quick fixes.
