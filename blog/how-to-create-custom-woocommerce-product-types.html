How to Create Custom WooCommerce Product Types

Hello fellow developers! I'm Shiv Parmar, a WordPress developer based in Rajkot, India. Over the past few years, I’ve had the opportunity to build custom e-commerce solutions for clients across the globe. While WooCommerce comes packed with standard product types—Simple, Grouped, External/Affiliate, and Variable—real-world client projects often demand custom commerce logic.

Whether you are building a store for equipment rentals, event ticketing, digital subscriptions with unique delivery terms, or custom service bookings, using standard product types with extra meta fields can quickly lead to messy workarounds. The cleanest and most scalable approach is to register a Custom WooCommerce Product Type.

In this comprehensive guide, I will walk you through creating a custom "Rental Product" type from scratch using PHP, JavaScript, and custom admin controls. Let's get started!

Understanding the Architecture

Before diving into code, it helps to understand how WooCommerce treats products behind the scenes. Products in WooCommerce are custom post types (product), but their behavior, inventory management, pricing structure, and user interface are controlled by PHP classes extending WC_Product.

To create a custom product type, we need to complete five core steps:

  1. Define a new PHP class that extends WC_Product (or WC_Product_Simple).
  2. Register the product type in WooCommerce admin dropdowns.
  3. Configure the admin display panels using PHP and JavaScript.
  4. Save custom product meta fields safely.
  5. Render the front-end "Add to Cart" template for our new product type.

Key Insight: Whenever your custom product type shares basic pricing, inventory, or shipping logic with simple products, extend WC_Product_Simple instead of WC_Product. This saves you from recreating standard price calculation and inventory tracking methods from scratch.

Step 1: Registering the Custom Product Class

First, let me create our custom class. I'll call it WC_Product_Rental. We will place this inside our custom plugin or child theme's functions.php file (preferably wrapped in a plugin structure).

<?php
/**
 * Register Custom Product Class: Rental Product
 */
function sp_register_rental_product_type() {

    class WC_Product_Rental extends WC_Product_Simple {

        public function __construct( $product ) {
            $this->product_type = 'rental';
            parent::__construct( $product );
        }

        public function get_type() {
            return 'rental';
        }

        // Custom getter for rental duration
        public function get_rental_duration_days() {
            return $this->get_meta( '_rental_duration_days', true );
        }
    }
}
add_action( 'init', 'sp_register_rental_product_type' );

In this code snippet, we extend WC_Product_Simple, setting the product_type property to rental. Returning rental in the get_type() method ensures WooCommerce recognizes this class whenever the product type is set to rental.

Step 2: Adding the Product Type to the Admin Selector

Next, we need to tell WooCommerce to include "Rental Product" in the backend product type drop-down list on the edit product screen. We also need to map the internal type string to our PHP class.

<?php
/**
 * Add 'Rental' to WooCommerce product type dropdown selector
 */
function sp_add_rental_product_type( $types ) {
    $types['rental'] = __( 'Rental Product', 'sp-rental' );
    return $types;
}
add_filter( 'product_type_selector', 'sp_add_rental_product_type' );

/**
 * Map 'rental' product type to our custom class
 */
function sp_load_rental_product_class( $classname, $product_type ) {
    if ( $product_type === 'rental' ) {
        $classname = 'WC_Product_Rental';
    }
    return $classname;
}
add_filter( 'woocommerce_product_class', 'sp_load_rental_product_class', 10, 2 );

Step 3: Customizing the Admin Product Data Panel

WooCommerce uses tabs to manage prices, inventory, shipping, and attributes in the admin panel. By default, our custom product type won't display price fields or shipping tabs until we explicitly tell WooCommerce which tabs apply to it.

Using JavaScript to Show Core Panels

WooCommerce uses jQuery in the admin backend to hide and show tab options dynamically based on CSS classes like show_if_simple or show_if_rental.

/**
 * Enqueue JavaScript to handle backend tab visibility for Rental Products
 */
function sp_rental_admin_custom_js() {
    if ( 'product' !== get_post_type() ) {
        return;
    }
    ?>
    <script type="text/javascript">
        jQuery(document).ready(function($) {
            // Show standard general pricing tab options for rental products
            $('.options_group.pricing').addClass('show_if_rental');
            
            // Trigger visibility on tab load
            if ($('#product-type').val() === 'rental') {
                $('.show_if_simple').show();
                $('.show_if_rental').show();
            }
            
            $('#product-type').on('change', function() {
                if ($(this).val() === 'rental') {
                    $('.show_if_simple').show();
                    $('.show_if_rental').show();
                }
            });
        });
    </script>
    <?php
}
add_action( 'admin_footer', 'sp_rental_admin_custom_js' );

Adding Custom Input Fields for Rental Products

Now, let's add a custom field specifically for rental duration (in days) inside the General product tab using WooCommerce built-in form helpers.

<?php
/**
 * Add custom rental settings fields to General tab
 */
function sp_add_rental_custom_fields() {
    echo '<div class="options_group show_if_rental">';
    
    woocommerce_wp_text_input( array(
        'id'          => '_rental_duration_days',
        'label'       => __( 'Rental Duration (Days)', 'sp-rental' ),
        'placeholder' => 'e.g. 3',
        'desc_tip'    => 'true',
        'description' => __( 'Enter default rental duration in total days.', 'sp-rental' ),
        'type'        => 'number',
        'custom_attributes' => array(
            'step' => '1',
            'min'  => '1',
        ),
    ) );

    echo '</div>';
}
add_action( 'woocommerce_product_options_general_product_data', 'sp_add_rental_custom_fields' );

Step 4: Saving Custom Product Meta Data

When an admin clicks "Update" or "Publish" on a product, WooCommerce fires specific hook actions for meta saving. We must catch our custom input field, sanitize it thoroughly, and save it to the database.

<?php
/**
 * Save custom rental fields during product save
 */
function sp_save_rental_custom_fields( $post_id ) {
    $rental_duration = isset( $_POST['_rental_duration_days'] ) ? sanitize_text_field( $_POST['_rental_duration_days'] ) : '';

    if ( ! empty( $rental_duration ) ) {
        update_post_meta( $post_id, '_rental_duration_days', absint( $rental_duration ) );
    } else {
        delete_post_meta( $post_id, '_rental_duration_days' );
    }
}
add_action( 'woocommerce_process_product_meta_rental', 'sp_save_rental_custom_fields' );

Step 5: Front-end Add to Cart Rendering

On the front-end product single page, WooCommerce looks for a dynamic action hook matching your custom product type: woocommerce_{product_type}_add_to_cart. Without hooking into this action, the "Add to Cart" button will not display on your single product page.

<?php
/**
 * Custom template hook for Rental product Add to Cart button
 */
function sp_rental_add_to_cart_template() {
    global $product;

    if ( $product->is_type( 'rental' ) ) {
        // We reuse simple product template for base functionality
        wc_get_template( 'single-product/add-to-cart/simple.php' );
    }
}
add_action( 'woocommerce_rental_add_to_cart', 'sp_rental_add_to_cart_template' );

If you want to display the rental duration on the single product page right before the purchase button, you can inject it via custom frontend hooks:

<?php
/**
 * Display Rental duration metadata on the single product page
 */
function sp_display_rental_info() {
    global $product;

    if ( $product && $product->is_type( 'rental' ) ) {
        $duration = $product->get_meta( '_rental_duration' );
        echo '<p class="rental-duration">Rental Duration: ' . esc_html( $duration ) . '</p>';
    }
}
add_action( 'woocommerce_single_product_summary', 'sp_display_rental_info', 15 );
?>
