How to Create Custom WooCommerce Product Types

While WooCommerce comes out of the box with versatile product types like Simple, Grouped, External, and Variable, real-world businesses often need custom solutions that go beyond these defaults.

Whether you are building a store for equipment rentals, custom digital subscriptions, service-based appointments, or bundled products, knowing how to register custom WooCommerce product types is an invaluable skill. Why Create a Custom WooCommerce Product Type?

Standard WooCommerce product types cover basic retail scenarios. However, specialized business models demand custom options, specific metadata, and unique user flows. Creating a custom product type allows you to:

  • Show or hide specific metaboxes in the WordPress admin panel.
  • Add custom admin fields tailored to your business model (e.g., rental duration, deposit fees).
  • Modify the add-to-cart behavior and template rendering on the frontend.
  • Keep your code clean and object-oriented by extending WooCommerce core classes.

For this guide, we will build a custom product type called Rental Product.

Step 1: Register the Custom PHP Product Class

WooCommerce utilizes Object-Oriented PHP for handling products. Every product type is represented by a class extending WC_Product. To create our custom type, we first need to define a class that extends WC_Product or any existing subclass like WC_Product_Simple.

Add the following PHP snippet to your custom plugin or your theme's functions.php file:

add_action( 'plugins_loaded', 'sp_register_rental_product_type_class' );

function sp_register_rental_product_type_class() {
    if ( ! class_exists( 'WC_Product' ) ) {
        return;
    }

    class WC_Product_Rental extends WC_Product {
        
        public function __construct( $product = 0 ) {
            $this->product_type = 'rental';
            parent::__construct( $product );
        }

        public function get_type() {
            return 'rental';
        }
    }
}

By declaring $this->product_type = 'rental'; and overriding the get_type() method, WooCommerce recognizes this class as the designated handler for the rental product type.

Step 2: Add the Product Type to the Admin Dropdown

Next, we need to ensure site administrators can select "Rental Product" from the WooCommerce product data dropdown menu on the Edit Product screen. We do this using the product_type_selector filter hook.

add_filter( 'product_type_selector', 'sp_add_rental_product_type' );

function sp_add_rental_product_type( $types ) {
    $types['rental'] = __( 'Rental Product', 'shiv-parmar' );
    return $types;
}

Once you add this code, navigate to your WordPress dashboard, create a new product, and check the "Product Data" dropdown. You will see "Rental Product" listed alongside Simple, Grouped, and Variable products.

Step 3: Show and Hide Relevant Data Tabs via JavaScript

When you switch product types in the WooCommerce admin, WooCommerce uses JavaScript to show or hide relevant product data tabs (like General, Inventory, Shipping, and Attributes). Since WooCommerce does not natively know which tabs our custom product type needs, all panels will hide by default.

We can fix this by enqueueing a lightweight inline JavaScript snippet in the admin panel:

add_action( 'admin_footer', 'sp_rental_product_custom_js' );

function sp_rental_product_custom_js() {
    if ( 'product' !== get_post_type() ) {
        return;
    }
    ?>
    <script type="text/javascript">
        jQuery( document ).ready( function( $ ) {
            // Show price and stock tabs for rental products
            $( '.options_group.pricing' ).addClass( 'show_if_rental' );
            $( '.inventory_options' ).addClass( 'show_if_rental' );
            $( '.show_if_simple' ).addClass( 'show_if_rental' );

            // Trigger WooCommerce view updates
            $( '#product-type' ).trigger( 'change' );
        });
    </script>
    <?php
}

In this snippet, adding the CSS class show_if_rental to WooCommerce elements ensures that general pricing, inventory settings, and simple options appear seamlessly when "Rental Product" is selected.

Step 4: Add Custom Meta Fields for Your Product Type

Now let's add custom fields unique to our rental product, such as "Daily Rental Fee" and "Security Deposit". We will hook into woocommerce_product_options_general_product_data to render the HTML fields and woocommerce_process_product_meta to save the values.

// Add Custom Fields to Admin General Tab
add_action( 'woocommerce_product_options_general_product_data', 'sp_add_rental_custom_fields' );

function sp_add_rental_custom_fields() {
    echo '<div class="options_group show_if_rental">';
    
    woocommerce_wp_text_input( array(
        'id'          => '_rental_security_deposit',
        'label'       => __( 'Security Deposit ($)', 'shiv-parmar' ),
        'placeholder' => '50',
        'desc_tip'    => 'true',
        'description' => __( 'Enter refundable security deposit amount.', 'shiv-parmar' ),
        'type'        => 'number',
        'custom_attributes' => array(
            'step' => 'any',
            'min'  => '0'
        )
    ) );

    echo '</div>';
}

// Save Custom Field Data
add_action( 'woocommerce_process_product_meta', 'sp_save_rental_custom_fields' );

function sp_save_rental_custom_fields( $post_id ) {
    $rental_deposit = isset( $_POST['_rental_security_deposit'] ) ? sanitize_text_field( $_POST['_rental_security_deposit'] ) : '';
    update_post_meta( $post_id, '_rental_security_deposit', $rental_deposit );
}

Step 5: Styling Admin Fields with CSS

To ensure your custom fields blend seamlessly into WooCommerce's interface, you can style them using admin CSS hooks:

add_action( 'admin_head', 'sp_rental_product_admin_css' );

function sp_rental_product_admin_css() {
    echo '<style>
        #woocommerce-product-data ul.wc-tabs li.rental_options a::before {
            content: "\f283";
            font-family: dashicons;
        }
        .options_group.show_if_rental {
            padding: 12px 20px;
            border-top: 1px solid #eee;
        }
    </style>';
}

Step 6: Display Custom Information on the Frontend

Now that backend functionality is set up, we need to ensure our customers see the rental deposit on the single product page and enable the "Add to Cart" button properly.

By default, WooCommerce uses template hooks to display add-to-cart buttons for each product type. We can reuse the simple product template or build a custom action hook:

// Connect rental product type to the single product add-to-cart template
add_action( 'woocommerce_rental_add_to_cart', 'woocommerce_simple_add_to_cart', 30 );

// Display deposit details on the product page
add_action( 'woocommerce_before_add_to_cart_form', 'sp_display_rental_deposit_info' );

function sp_display_rental_deposit_info() {
    global $product;

    if ( $product->is_type( 'rental' ) ) {
        $deposit = get_post_meta( $product->get_id(), '_rental_security_deposit', true );
        if ( ! empty( $deposit ) ) {
            echo '<p class="rental-deposit-info" style="color: #2c3e50; font-weight: bold;">';
            echo sprintf( __( 'Refundable Deposit: $%s', 'shiv-parmar' ), esc_html( $deposit ) );
            echo '</p>';
        }
    }
}

Key Development Insight: Always rely on WooCommerce standard product hooks and class inheritance rather than writing isolated code. Extending core classes guarantees compatibility with third-party plugins, custom queries, REST API endpoints, and database updates!

By following these steps—extending WC_Product, registering the type in selectors, toggling admin tabs via JavaScript, and handling meta fields cleanly—you can tailor WooCommerce to fit practically any business model.
