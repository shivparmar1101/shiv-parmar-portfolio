WordPress Security Hardening Guide 2026

WordPress powers 43% of the web, making it the #1 target for hackers. After securing 30+ sites, here's the exact security checklist I follow for every WordPress project.

1. Change Default Login URL

The default /wp-admin and /wp-login.php URLs are the first thing bots attack. Use WPS Hide Login to change it to a custom URL like /my-secret-login.

2. Enable Two-Factor Authentication

2FA adds a second layer of protection. Even if someone guesses your password, they can't login without the authentication code from your phone.

// Install WP 2FA plugin
// Settings → WP 2FA → Configure 2FA
// Enable TOTP (Google Authenticator)

3. Limit Login Attempts

By default, WordPress allows unlimited login attempts. This makes brute force attacks trivially easy. Limit to 5 attempts per 15 minutes.

4. Set Proper File Permissions

Incorrect file permissions are the most common vulnerability I see. Here's the correct setup:

  • /wp-config.php → 400 or 440
  • /.htaccess → 444
  • /wp-content/ → 755
  • All other files → 644

5. Disable XML-RPC

XML-RPC is used for pingbacks and remote publishing, but it's also a massive security hole. Unless you specifically need it, disable it completely.

// In .htaccess
<Files xmlrpc.php>
  Require all denied
</Files>

6. Hide WordPress Version

Showing your WordPress version tells attackers exactly which vulnerabilities to exploit. Remove it from headers and source code.

7. Install a Firewall Plugin

Wordfence or Sucuri firewall blocks malicious traffic before it reaches your server. This is your first line of defense against DDoS and brute force attacks.

8. Regular Malware Scanning

Scan your site weekly for malware, phishing redirects, and suspicious code. Wordfence scanning catches 99% of known threats.

9. Keep Everything Updated

60% of hacked WordPress sites were running outdated software. Always update WordPress core, themes, and plugins within 48 hours of release.

10. Backup Strategy

Even with perfect security, things can go wrong. Maintain daily backups stored off-site (not on your server). UpdraftPlus or BlogVault are reliable options.

Security isn't a one-time setup — it's an ongoing process. Review your security posture monthly and stay updated on new threats.

Quick Security Checklist

  1. Change login URL
  2. Enable 2FA
  3. Limit login attempts
  4. Set correct file permissions
  5. Disable XML-RPC
  6. Hide WordPress version
  7. Install firewall
  8. Schedule malware scans
  9. Keep everything updated
  10. Maintain off-site backups
