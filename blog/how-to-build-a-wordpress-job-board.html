In this post, I will walk you through building a lightweight, custom WordPress Job Board from scratch using PHP, JavaScript, and CSS.

Here is an overview of the implementation roadmap we will follow:

  1. Registering the Custom Post Type (CPT) and custom taxonomies.

  3. Building dynamic, real-time AJAX filtering using Vanilla JavaScript.
  4. Styling the frontend job cards with responsive CSS.

Step 1: Registering the Job Custom Post Type & Taxonomies

The groundwork of any custom feature in WordPress is clean data architecture. For our job board, we will create a Custom Post Type named job_listing along with a custom taxonomy called job_type (e.g., Full-Time, Part-Time, Contract, Remote).

Place this code inside your custom functionality plugin or your child theme's functions.php file:

function sp_register_job_board_cpt() {
    $labels = array(
        'name'               => _x( 'Jobs', 'post type general name' ),
        'singular_name'      => _x( 'Job Listing', 'post type singular name' ),
        'menu_name'          => _x( 'Job Board', 'admin menu' ),
        'add_new'            => _x( 'Add New', 'job' ),
        'add_new_item'       => __( 'Add New Job Listing' ),
        'edit_item'          => __( 'Edit Job Listing' ),
        'all_items'          => __( 'All Jobs' ),
        'search_items'       => __( 'Search Jobs' ),
        'not_found'          => __( 'No jobs found' ),
    );

    $args = array(
        'labels'             => $labels,
        'public'             => true,
        'publicly_queryable' => true,
        'show_ui'            => true,
        'show_in_menu'       => true,
        'query_var'          => true,
        'rewrite'            => array( 'slug' => 'jobs' ),
        'capability_type'    => 'post',
        'has_archive'        => true,
        'hierarchical'       => false,
        'menu_position'      => 5,
        'menu_icon'          => 'dashicons-portfolio',
        'supports'           => array( 'title', 'editor', 'thumbnail', 'excerpt' ),
        'show_in_rest'       => true,
    );

    register_post_type( 'job_listing', $args );

    // Register Job Type Taxonomy
    register_taxonomy( 'job_type', array( 'job_listing' ), array(
        'hierarchical'      => true,
        'labels'            => array( 'name' => 'Job Types', 'singular_name' => 'Job Type' ),
        'show_ui'           => true,
        'show_admin_column' => true,
        'query_var'         => true,
        'rewrite'           => array( 'slug' => 'job-type' ),
        'show_in_rest'      => true,
    ));
}
add_action( 'init', 'sp_register_job_board_cpt' );

Step 2: Adding Custom Meta Fields for Job Details

Every job listing requires specific metadata like Company Name, Job Location, and Salary Range. Writing native WordPress meta boxes keeps your platform dependency-free and ultra-fast.

// Add Meta Box
function sp_add_job_meta_boxes() {
    add_meta_box(
        'sp_job_details',
        'Job Specifications',
        'sp_job_meta_box_callback',
        'job_listing',
        'normal',
        'high'
    );
}
add_action( 'add_meta_boxes', 'sp_add_job_meta_boxes' );

// Callback function to render admin fields
function sp_job_meta_box_callback( $post ) {
    wp_nonce_field( 'sp_save_job_details', 'sp_job_details_nonce' );
    
    $company  = get_post_meta( $post->ID, '_sp_company_name', true );
    $location = get_post_meta( $post->ID, '_sp_job_location', true );
    $salary   = get_post_meta( $post->ID, '_sp_job_salary', true );
    ?>
    <p>
        <label for="sp_company_name"><strong>Company Name:</strong></label><br>
        <input type="text" id="sp_company_name" name="sp_company_name" value="<?php echo esc_attr( $company ); ?>" class="widefat">
    </p>
    <p>
        <label for="sp_job_location"><strong>Location (e.g. Remote, Rajkot, NYC):</strong></label><br>
        <input type="text" id="sp_job_location" name="sp_job_location" value="<?php echo esc_attr( $location ); ?>" class="widefat">
    </p>
    <p>
        <label for="sp_job_salary"><strong>Salary Range:</strong></label><br>
        <input type="text" id="sp_job_salary" name="sp_job_salary" value="<?php echo esc_attr( $salary ); ?>" class="widefat">
    </p>
    <?php
}

// Save Metadata Securely
function sp_save_job_meta_data( $post_id ) {
    if ( ! isset( $_POST['sp_job_details_nonce'] ) || ! wp_verify_nonce( $_POST['sp_job_details_nonce'], 'sp_save_job_details' ) ) return;
    if ( defined( 'DOING_AUTOSAVE' ) && DOING_AUTOSAVE ) return;
    if ( ! current_user_can( 'edit_post', $post_id ) ) return;

    if ( isset( $_POST['sp_company_name'] ) ) {
        update_post_meta( $post_id, '_sp_company_name', sanitize_text_field( $_POST['sp_company_name'] ) );
    }
    if ( isset( $_POST['sp_job_location'] ) ) {
        update_post_meta( $post_id, '_sp_job_location', sanitize_text_field( $_POST['sp_job_location'] ) );
    }
    if ( isset( $_POST['sp_job_salary'] ) ) {
        update_post_meta( $post_id, '_sp_job_salary', sanitize_text_field( $_POST['sp_job_salary'] ) );
    }
}
add_action( 'save_post', 'sp_save_job_meta_data' );

Step 3: Implementing Real-Time AJAX Filtering

Modern job seekers expect instant filter results without annoying browser updates or page reloads. We can achieve this easily using JavaScript's fetch() API combined with standard WP_Query in PHP.

1. Vanilla JavaScript Client Script

Create a JavaScript file (e.g., job-filter.js) and enqueue it properly using wp_enqueue_script while passing ajax_url via wp_localize_script:

document.addEventListener('DOMContentLoaded', function() {
    const filterSelect = document.getElementById('sp-job-type-filter');
    const resultsContainer = document.getElementById('sp-job-listings');

    if (filterSelect) {
        filterSelect.addEventListener('change', function() {
            const selectedType = this.value;
            const formData = new FormData();
            
            formData.append('action', 'sp_filter_jobs');
            formData.append('job_type', selectedType);

            fetch(sp_ajax_object.ajax_url, {
                method: 'POST',
                body: formData
            })
            .then(response => response.text())
            .then(html => {
                resultsContainer.innerHTML = html;
            })
            .catch(error => console.error('Filter Error:', error));
        });
    }
});

2. PHP AJAX Handler

Add this backend listener in your PHP setup to return updated listings dynamically:

function sp_ajax_filter_jobs_handler() {
    $job_type = isset($_POST['job_type']) ? sanitize_text_field($_POST['job_type']) : '';

    $args = array(
        'post_type'      => 'job_listing',
        'posts_per_page' => 10,
        'post_status'    => 'publish',
    );

    if ( ! empty( $job_type ) ) {
        $args['tax_query'] = array(
            array(
                'taxonomy' => 'job_type',
                'field'    => 'slug',
                'terms'    => $job_type,
            ),
        );
    }

    $query = new WP_Query( $args );

    if ( $query->have_posts() ) :
        while ( $query->have_posts() ) : $query->the_post();
            $company  = get_post_meta( get_the_ID(), '_sp_company_name', true );
            $location = get_post_meta( get_the_ID(), '_sp_job_location', true );
            $salary   = get_post_meta( get_the_ID(), '_sp_job_salary', true );
            ?>
            <article class="job-card">
                <h3 class="job-title"><a href="<?php the_permalink(); ?>"><?php the_title(); ?></a></h3>
                <div class="job-details">
                    <span class="company"><strong>Company:</strong> <?php echo esc_html( $company ); ?></span> | 
                    <span class="location"><strong>Location:</strong> <?php echo esc_html( $location ); ?></span> | 
                    <span class="salary"><strong>Salary:</strong> <?php echo esc_html( $salary ); ?></span>
                </div>
            </article>
            <?php
        endwhile;
        wp_reset_postdata();
    else :
        echo '<p class="no-jobs">No job listings found for this category.</p>';
    endif;

    wp_die();
}
add_action( 'wp_ajax_sp_filter_jobs', 'sp_ajax_filter_jobs_handler' );
add_action( 'wp_ajax_nopriv_sp_filter_jobs', 'sp_ajax_filter_jobs_handler' );

Developer Best Practices to Remember

When delivering custom WordPress applications for client sites, keep these essential practices in mind:

  • Security First: Always validate inputs using sanitize_text_field() and escape dynamic outputs using esc_html() or esc_attr().
  • SEO Optimization: Integrate standard Google JSON-LD JobPosting structured data markup so open roles rank on Google Jobs natively.
  • Frontend Submission Options: If employers submit positions directly, build a frontend form tied to wp_insert_post() while setting default status to 'pending' for editorial approval.

Wrapping Up

Building a custom WordPress Job Board gives you total authority over performance, extension capabilities, and code efficiency. By utilizing standard WordPress APIs combined with AJAX and clean CSS, you create a seamless user experience tailored to your exact business needs.
