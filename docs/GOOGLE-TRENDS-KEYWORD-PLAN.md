## 📋 GOOGLE TRENDS RESEARCH PROCESS (Repeat for Each Group)

### Process:
```
1. Google Trends khole (https://trends.google.com)
2. Settings: Worldwide, Past 12 months, Web Search
3. First keyword type karo → Note karo:
   - Interest over time (steady hoi ke seasonal?)
   - Related topics (rising + top)
   - Related queries (rising + top)
   - Regional interest (jya sabse vadhare hoi)
4. "Compare" button dabavo → Dusra keyword type karo
5. Compare karo:
   - Konu volume vadhare che?
   - Konu trend vadhare che?
   - Related queries different che?
6. Screenshot lo / notes lo
7. Next keyword pair jao
```

### What to Note Down:
| Data Point | Why Important | Where to Use |
|-----------|---------------|--------------|
| **Interest Over Time** | Seasonal vs Evergreen | Content calendar planning |
| **Related Queries (Rising)** | New trending keywords | Blog post topics |
| **Related Queries (Top)** | High-volume keywords | Meta tags, H1 |
| **Regional Interest** | Geographic targeting | Location-specific content |
| **Compared Keywords** | Which phrasing is better | Meta title optimization |

## 🔍 GOOGLE TRENDS + SEO COMBO STRATEGY

### How to Use Google Trends Data for SEO:

#### 1. Meta Title Optimization
```
Google Trends ma "hire wordpress developer" vs "wordpress developer for hire" compare karo.
→ Jo konu volume vadhare che, te title ma use karo.
→ Example: If "hire wordpress developer" = higher → Use in title
```

#### 2. Content Calendar Planning
```
Google Trends ma seasonal trends dekho.
→ WooCommerce spike Oct-Dec → Oct ma ecommerce content publish karo
→ WordPress security always trending → Security content evergreen rakho
```

#### 3. Blog Post Topics
```
Google Trends "Related Queries (Rising)" ma jo koi navi query che.
→ Turant blog post lakho - competition low hoi
→ Example: "wordpress ai integration" rising che → Post lakho immediately
```

#### 4. Geographic Targeting
```
Google Trends ma regional interest dekho.
→ Jya sabse vadhare interest che, tya language ma content banao
→ Example: Germany ma high interest → German content consider karo
```

#### 5. Competitor Analysis
```
Google Trends ma competitor keywords compare karo.
→ Tamara brand vs competitor brand
→ Jo competitor vadhare trending che → Tamari strategy change karo
```
