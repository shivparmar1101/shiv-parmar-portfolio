## 📋 WORKFLOW STEPS (Daily/Weekly/Monthly)

### ⏰ STEP 1: DAILY CHECK (5 Minutes - Every Morning)

```
🕐 KARVANI RITE:
1. Phone/Computer khole
2. Google Search Console kholo
3. "Performance" > "Queries" par jao
4. Yesterday vs Previous period compare karo
5. Note karo:
   - Clicks vadhya ke ghatta?
   - Impressions vadhya ke ghatta?
   - Koi navi keyword aavi?
   - Koi keyword disappeared thayo?
```

**Daily Checklist:**
- [ ] Google Search Console - Queries tab check
- [ ] Koi keyword ranking ghatti? → Turant investigate karo
- [ ] Koi navi keyword ranking ma aavi? → Content optimize karo
- [ ] Competitor mention check (Google search)

### 📈 STEP 3: MONTHLY DEEP CHECK (2 Hours - First Sunday)

```
🕐 KARVANI RITE:

PART A: Keyword Audit (1 hour)
1. Google Search Console kholo
2. "Performance" > "Queries" > "Date: Last 28 days"
3. Export karo (Download button)
4. Excel ma open karo:
   - Column A: Keyword
   - Column B: Clicks
   - Column C: Impressions
   - Column D: CTR
   - Column E: Position

5. Sort by Position (ascending):
   - Position 1-10 = Ranking well ✅
   - Position 11-20 = Optimize karo ⚠️
   - Position 21-50 = Content change needed 🔴
   - Position 50+ = Review content completely 🚫

PART B: Content Review (30 minutes)
1. Har page nu meta description check karo:
   - 120-320 chars che?
   - Primary keyword che?
   - CTA che?

2. Har page nu title check karo:
   - 30-65 chars che?
   - Primary keyword che?
   - "| Shiv Parmar" suffix che?

PART C: Competitor Check (30 minutes)
1. Google ma "hire wordpress developer" search karo
2. Top 10 results note karo:
   - Kon ranking ma che?
   - Tamara mukable shu different che?
   - Kaya keywords tame miss karo cho?

3. Google Trends ma competitor keywords compare karo:
   - "toptal wordpress developer" vs "shiv parmar wordpress"
   - "upwork wordpress developer" vs "hire shiv parmar"
```

**Monthly Checklist:**
- [ ] Keyword ranking spreadsheet update
- [ ] Ghatta gaya keywords identify karo
- [ ] Vadhya keywords identify karo
- [ ] Navi rising queries note karo
- [ ] Meta tags review (all pages)
- [ ] Content gaps identify karo
- [ ] Competitor analysis update
- [ ] Strategy update based on data

### B. ALERT SYSTEM (When to Take Action)

#### 🔴 RED ALERT - Take Action Immediately
| Alert | Trigger | Action |
|-------|---------|--------|
| Keyword dropped 5+ positions | Position change > 5 | Check page, update content, check backlinks |
| Traffic dropped 20%+ | Clicks decrease > 20% | Check Google Search Console for issues |
| Competitor outranked | Competitor moved above you | Analyze their content, update yours |
| Page not indexed | Page missing from index | Check robots.txt, submit to GSC |

#### 🟡 YELLOW ALERT - Review This Week
| Alert | Trigger | Action |
|-------|---------|--------|
| Keyword dropped 1-4 positions | Position change 1-4 | Monitor, consider content update |
| CTR below 2% | CTR < 2% | Update meta description |
| New competitor appears | New in top 10 | Analyze their strategy |
| Impression increase without click increase | Impressions up, clicks same | Update meta description with better CTA |

#### 🟢 GREEN ALERT - Good / Monitor
| Alert | Trigger | Action |
|-------|---------|--------|
| Keyword improved position | Position change +1 or more | Document, maintain strategy |
| New keyword in top 20 | New keyword ranking | Consider creating more content |
| Traffic increased 10%+ | Clicks increase > 10% | Document what worked |
| Rising trend on Google Trends | Interest increasing | Create content early |

## 📝 KEYWORD CHECK WORKFLOW (Step-by-Step)

### WORKFLOW 1: New Keyword Discovery

```
STEP 1: Google Trends > Related Queries (Rising) par jao
STEP 2: Koi navi keyword jova mili?
   → YES: Google Search ma search karo
   → YES: Keyword volume check karo (Google Keyword Planner)
   → YES: Competition check karo (Top 10 results dekho)
   → TAMARI SITE RELEVANT CHE? → YES: Content create karo
   → NO: Skip karo

STEP 3: Blog post / page update karo
   → Meta title ma keyword add karo
   → Meta description ma keyword add karo
   → H2/H3 headings ma use karo
   → Content ma naturally include karo
```

### WORKFLOW 2: Keyword Ranking Drop Fix

```
STEP 1: GSC ma check karo - keyword position shu thayo?
STEP 2: Reason identify karo:
   → Google Algorithm Update? → Wait 2 weeks, check again
   → Competitor better content banavyu? → Update your content
   → Backlinks ghatta? → New backlinks build karo
   → Technical issue? → Page speed, mobile check karo
   → Content outdated? → Update content, add new info

STEP 3: Fix karo based on reason:
   → Content update karo (add new info, better examples)
   → Meta tags optimize karo
   → Internal links add karo
   → Schema markup check karo
   → Social media par share karo

STEP 4: 2 weeks pachhi re-check karo
   → Improve thayo? → Document karo
   → Same? → Different strategy try karo
   → Worse? → Deep audit karo
```

### WORKFLOW 3: Trending Topic Content Creation

```
STEP 1: Google Trends "Trending Now" par jao
STEP 2: WordPress/Web Development related topic?
   → YES: Continue
   → NO: Skip

STEP 3: Quick research karo:
   → Topic shu che? (5 min Google search)
   → Koi competitor e already content banavyu? (Check top 10)
   → Tamare real experience che? (If yes, write)
   → Search volume kitlu che? (Google Keyword Planner)

STEP 4: Content create karo (within 24-48 hours):
   → Blog post title with keyword
   → 1000+ words detailed content
   → Meta title + description optimized
   → Schema markup add karo
   → Sitemap update karo

STEP 5: Publish + Share:
   → Social media par share karo
   → LinkedIn par article publish karo
   → Google Search Console ma submit karo
```

### WORKFLOW 4: Competitor Keyword Stealing

```
STEP 1: Google Trends ma competitor keyword search karo
   → "toptal wordpress developer"
   → "upwork wordpress developer"
   → "fiverr wordpress developer"

STEP 2: Related queries check karo
   → Kaya queries tara competitor ne target kar rahe che?
   → Tamne target karva joie?

STEP 3: Content create karo targeting those keywords:
   → "Why Hire Direct WordPress Developer vs Upwork"
   → "Toptal vs Freelance WordPress Developer: Cost Comparison"
   → "Best WordPress Developer for Small Business (Not Fiverr)"

STEP 4: Meta tags optimize karo:
   → Title: Include competitor keyword naturally
   → Description: Highlight your advantage
```
